## Build, install, test
```
cd ~/mpc-vst-cratedigger
tests/run.sh                         # offline test (Docker image crate-sdk-x64), must print OK
python3 tools/make_tui.py --preview  # skins/ + offline composites in build/preview/*.png
./build-sdk.sh beta                  # "Crate Digger 2 Beta" (uid CrDB) -> build/sdk/{armv7,aarch64}/"sd88me - VST - Crate Digger 2 Beta"
```
- First build downloads the engine bundles from release `cratedigger-vst-v1.3.0` into `build/engine-<cpu>/` (needs `gh`). `build/` is ignored; keep disk free (`/tmp` is a small RAM disk: don't download there).
- Live III: `python3 ~/mpc-310-private/plugin-vibecode-sdk/plugin-vibecode-sdk/tools/mpc_remote.py 192.168.2.217 --yes update "build/sdk/aarch64/sd88me - VST - Crate Digger 2 Beta"` then `... restart`. ASK THE USER before every restart (unsaved data is lost). Screenshot before tapping (`~/mpc-vst-plugins/tools/screenshot.sh root@192.168.2.217 out.png`).
- Force: tar the armv7 folder into `/sdcard/Synths/`, then with MPC stopped (`systemctl stop acvs`) run `build/cd2_register.sh` (copied to `/tmp` with `build/plugin_list.awk`; it edits MPC.settings, key `pluginList-arm`, uid 43724442), then `systemctl start acvs`. Ask first. The `mpc` MCP tools drive the Force.
- The SDK validator always reports "plugin.json missing file32/file64": expected, one folder per CPU.
- Release identity when shipping: name "Crate Digger", uid `CrDg`, `build-sdk.sh` without `beta`; plugin.json version is 2.0.0 (placeholder; the owner may prefer another). Two zips per release (armv7, aarch64) is fine.

## Facts learned on hardware (add to SDK-PORTING.md when convenient)
- The MPC draws a Label at about 0.66 x its TUI height in pixels, and only has Titillium Web, Roboto, Nexa. `tools/make_tui.py` has `th(px)` for this and the previews use Titillium at that scale.
- The MPC draws an orange "Q" tag at the top-left of the active Q-Link group: keep panel titles 36+ px in from the corner.
- Parameter 0 (genre) is nudged to its top and back by the host on every prepare: a change counts only after ~40 ms (`pendingAt_`).
- A tap on a lit toggle arrives as two events ~130 ms apart: `stickyChanged` flips once per 300 ms (TAP_GAP_MS).
- Text readouts are int parameters whose value text is the display text; a counter parameter is bumped so the host re-reads, and `effGetParamDisplay` is wrapped so text can be 99 chars (SDK default is 31).
- Result rows: a Button whose value (0/1) lights a bar behind a Label bound to the same parameter.
- Old 1.x projects: effSetChunk is wrapped; text chunk "g=..;s=..;..." is read by `loadLegacy`. Offline-tested only, not with a real saved project.

## Skin: the MPC60 look is DONE (v5), layout approved
Current look (`tools/make_tui.py` + primitives in `tools/mockup_skin.py`; previews in `docs/skin-mockups/v5-mpc60/`, earlier looks in `v1..v4`): putty body, slate cheeks, bright green LCD with dark text, cream keys with a side wall and no borders, red SEARCH keys, dark KEYBOARD/utility keys, black knobs with white pointers, centred silk-screen titles, no screws, no DIG 1 badge. No maker's name or logo anywhere.
- PLAY: LCD header (NOW big, TIME top right, STATUS wide, SEARCH) + 8 result rows; TRANSPORT group (back, play/pause, stop, forward, SYNC) with PLAY/STOP lamps from `play_state`; page keys and SEARCH.
- FILTERS: the LCD has five columns (01 GENRE .. 05 COUNTRY) directly above the matching knob columns; the lower panel is the MPC60 pad-well grey with the same column lines; big arrow keys under each knob.
- FIND: LCD columns DISCOGS | YOUTUBE | CHANNEL; lower half = DISCOGS panel, one YOUTUBE section with its CHANNEL extension, and a far-right SEARCH column with KEYBOARD and SEARCH stacked; popup keyboard overlay (rows re-spaced).
- Master section top right: GAIN horizontal fader + stereo LEVEL meter (real output peaks).
- Hardware-learned rules for this skin: text draws at 0.66 x TUI height; keep titles centred (the Q tag covers the top-left corner of the active group); touch areas of neighbouring keys must not overlap (arrow keys have an 8 px pad).
Deployed: the Live III and the Force both received the build of 2026-11-08 up to the bigger arrows / borderless keys; commits after 97b767f (grey panel, FIND rearrangement, tidy-up) are built but not yet deployed (ask first, restarts lose unsaved data).
