# channels.txt: YouTube channels for the FIND tab's CHANNEL source.
# Put this file in the plugin's cratedigger/ folder (next to bin/), for example
#   /sdcard/Synths/sd88me - VST - Crate Digger/cratedigger/channels.txt
# One channel per line, up to 16: a channel link, an @handle, a UC... channel ID or a playlist link,
# then an optional name for the screen after a |. The installer keeps this file when you upgrade.
#
#https://www.youtube.com/@yourchannel | Your Channel
#@anotherchannel
#UCxxxxxxxxxxxxxxxxxxxxxx | Some Channel
#https://www.youtube.com/playlist?list=PLxxxxxxxxxxxx | A Playlist
